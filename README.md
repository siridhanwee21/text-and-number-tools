Text and Number Tools

About the Project

This is a simple Python project that works with text and numbers. It takes input from the user, performs different operations, and displays the results clearly.

Features

- Counts the number of words in a sentence.
- Finds the longest word in a sentence.
- Reverses a sentence.
- Checks whether a number is prime or not.

Technologies Used

- Python 3

How to Run

1. Download or clone this repository.

2. Open the project folder in VS Code or a terminal.

3. Run the following command:
   
   "python text_tools.py"

4. Enter a sentence and a number when prompted.

5. View the results in the terminal.

Sample Input

- Sentence: Python programming is very interesting
- Number: 7

Sample Output

- Word count: 5
- Longest word: programming
- Reversed sentence: gnitseretni yrev si gnimmargorp nohtyP
- 7 is a prime number.

Project Structure

- "text_tools.py" – Main Python program containing all four functions.
- "README.md" – Project description and instructions.
